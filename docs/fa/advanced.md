# تنظیمات پیشرفته

[بازگشت به README](../../README.fa.md) · [English](../en/advanced.md)

**Settings › Advanced** را باز کن. گزینه‌های ۱ تا ۶ فایل `server.conf` را تغییر می‌دهند و OpenVPN را Restart می‌کنند؛ کاربران چند ثانیه قطع می‌شوند و خودشان دوباره وصل می‌شوند.

## روش اعمال تغییر

1. تغییر را تأیید می‌کنی؛ پیش‌فرض «خیر» است.
2. از `server.conf` کنار خودش پشتیبان گرفته می‌شود و پنج نسخهٔ آخر می‌مانند.
3. OpenVPN ری‌استارت می‌شود و ابزار تا ۵ ثانیه منتظر پورت UDP می‌ماند.
4. اگر بالا نیاید، فایل قبلی برمی‌گردد و OpenVPN دوباره اجرا می‌شود. اگر این هم شکست بخورد، پیام فوری نمایش داده می‌شود.

این بررسی محلی است و ثابت نمی‌کند کلاینت‌ها از اینترنت به سرور می‌رسند.

## تنظیمات

| # | تنظیم | توضیح |
|---|---|---|
| ۱ | Traffic routing | **Full tunnel** همهٔ IPv4 کلاینت را از سرور می‌گذراند؛ **split tunnel** فقط شبکهٔ VPN را. رفتن به full اگر DNS نباشد، DNS پیش‌فرض اضافه می‌کند. Full tunnel به NAT سرور نیاز دارد |
| ۲ | DNS for clients | یک یا دو IPv4. در split tunnel استفاده نمی‌شود |
| ۳ | VPN network | یک `/24` خصوصی که به `.0` ختم شود و با مسیر موجود تداخل نداشته باشد. NAT هم همراه آن تغییر می‌کند. اگر NAT را این ابزار نساخته باشد رد می‌شود. آدرس‌های ثابت `client-config-dir` یا `ifconfig-pool-persist` به‌روز نمی‌شوند |
| ۴ | Data ciphers | `AES-256-GCM`، `AES-128-GCM`، `CHACHA20-POLY1305`، جدا با `:`. بقیه DCO را خاموش می‌کنند. کلاینت بدون رمز مشترک به پروفایل جدید نیاز دارد |
| ۵ | Keepalive | فاصلهٔ ping و مهلت به ثانیه. مهلت باید دست‌کم دو برابر فاصله باشد |
| ۶ | Log detail | از `0` تا `6`؛ `3` حالت عادی است. `4` به بالا برای عیب‌یابی است و ممکن است اطلاعات خصوصی را لاگ کند |
| ۷ | Download access | آدرس، پورت و کاربر SSH در دستورهای `scp` و `sftp`؛ بدون Restart |
| ۸ | New client lifetime | تعداد روز گواهی کلاینت‌های جدید؛ `0` یعنی پیش‌فرض Easy-RSA؛ بدون Restart |
| ۹ | Share link port | پورت TCP لینک موقت؛ بدون Restart |

## فایل تنظیمات

`/etc/darban/config` تنظیمات ابزار را نگه می‌دارد و فقط به‌صورت داده خوانده می‌شود، نه اجرا.

</div>

```text
DOWNLOAD_SSH_HOST=203.0.113.10
DOWNLOAD_SSH_PORT=22
DOWNLOAD_SSH_USER=root
CLIENT_CERT_DAYS=825
LINK_PORT=443
UPDATE_CHECK=no
```

<div dir="rtl">

`UPDATE_CHECK=no` اعلان روزانهٔ نسخهٔ جدید را خاموش می‌کند. از **Setup › Daily update notice** هم می‌توانی آن را تغییر دهی.
