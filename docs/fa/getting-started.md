# شروع کار

[بازگشت به README](../../README.fa.md) · [English](../en/getting-started.md)

از یک سرور تازه تا اولین کاربر متصل. هر قدم می‌گوید باید چه ببینی و اگر چیز دیگری دیدی چه کنی. معنی اصطلاح‌ها در [فرهنگ اصطلاحات](glossary.md) است.

## قدم ۱: سرور بگیر

یک VPS تازه با **Ubuntu 24.04 یا 26.04** از هر ارائه‌دهنده‌ای بگیر. سرور `amd64` انتخاب کن. پشتیبانی `arm64` هنوز در حال آزمون است.

**باید داشته باشی:** آدرس IP سرور و راه ورود با `root` یا کاربری که `sudo` دارد.

**اگر نداری:** در پنل ارائه‌دهنده نگاه کن. بیشتر ارائه‌دهنده‌ها آدرس و اطلاعات ورود را در صفحهٔ سرور نشان می‌دهند.

## قدم ۲: به سرور وصل شو

روی کامپیوتر خودت ترمینال را باز کن و وصل شو. به‌جای این آدرس، آدرس سرور خودت را بگذار:

</div>

```bash
ssh root@203.0.113.10
```

<div dir="rtl">

**باید ببینی:** خط فرمان سرور.

**اگر ندیدی:** آدرس و نام کاربری را در پنل ارائه‌دهنده بررسی کن. مستقیم وصل شو، نه از طریق VPN‌ای که قرار است تغییر کند.

## قدم ۳: دستور نصب را اجرا کن

</div>

```bash
curl -fsSL https://github.com/MohZeh/Darban-OVPN/releases/latest/download/get.sh | sudo bash
```

<div dir="rtl">

**باید ببینی:** `Step 1 of 2: Server address`

**اگر ندیدی:**
- `curl: command not found`: دستور `sudo apt update && sudo apt install -y curl` را اجرا کن و بعد دوباره دستور نصب را بزن.
- `No stable release is published yet`: آدرس یک نسخه را از صفحهٔ [Releases](https://github.com/MohZeh/Darban-OVPN/releases) بردار. در دستور، به‌جای `latest/download` بنویس `download/vX.Y.Z-rc.N`.

## قدم ۴: به پرسش‌ها جواب بده

هر پرسش یک پیشنهاد نشان می‌دهد. **با Enter آن را قبول کن.**

1. **Server address:** Enter بزن. دامنه اختیاری است و با آن لینک موقت بدون هشدار مرورگر باز می‌شود.
2. **VPN port:** Enter بزن.
3. **Install this server?** روی **Install now** Enter بزن.

تا پیش از جواب سوم، چیزی روی سرور تغییر نمی‌کند. برای دیدن برنامهٔ کامل، `2` را بزن و بعد روی **Show details** Enter بزن.

**باید ببینی:** پنج مرحلهٔ کوتاه و بعد `Your VPN server is ready`.

**اگر ندیدی:** صفحه خط‌های آخر لاگ را نشان می‌دهد. همان دستور را دوباره اجرا کن تا از همان‌جا ادامه دهد. برای برگرداندن همه‌چیز، دستوری را که روی صفحه آمده اجرا کن.

## قدم ۵: پورت VPN را در فایروال ارائه‌دهنده باز کن

بسیاری از ارائه‌دهنده‌ها در پنل خود فایروال دارند، معمولاً با نام **Firewall**، **Security Group** یا **Network Rules**. این ابزار آن را نمی‌بیند و نمی‌تواند تغییرش دهد.

قانونی اضافه کن که **ورود UDP روی پورت 1194**، یا پورتی که انتخاب کردی، را اجازه دهد.

**اگر ارائه‌دهنده چنین فایروالی ندارد:** به قدم بعد برو.

## قدم ۶: اولین کلاینت را بساز

کلاینت یعنی یک نفر یا یک دستگاه. ابزار بلافاصله بعد از نصب می‌پرسد:

1. **Create your first client now?** Enter بزن.
2. **Client name:** با Enter نام `client1` انتخاب می‌شود، یا نامی مثل `ali-phone` بنویس.
3. **How will the client get this profile?** برای **Temporary link** Enter بزن.
4. **Lock the private key with a password?** بدون دامنه، پیشنهاد «بله» است. Enter بزن و برای رمز کوتاه پیشنهادی، مثل `k7m-3xt-9vw`، دوباره Enter بزن.
5. **How long should the link work?** برای یک ساعت Enter بزن.

**باید ببینی:** لینکی که با `https://` شروع می‌شود و پورت TCP آن.

**اگر ندیدی:** [لینک باز نمی‌شود](troubleshooting.md#link-fails) را ببین.

آن پورت TCP را هم مثل قدم ۵ در فایروال ارائه‌دهنده باز کن. ابزار پورت را کنار لینک نشان می‌دهد.

## قدم ۷: لینک را بفرست

لینک را در هر پیام‌رسانی بفرست. پیش‌نمایش پیام‌رسان آن را مصرف نمی‌کند. لینک یک بار کار می‌کند، برای کسی که دکمهٔ داخل صفحه را بزند.

اگر سرور گواهی معتبر ندارد، ابزار یک متن کوتاه هم نشان می‌دهد. آن را همراه لینک بفرست، چون مرورگر برای این لینک هشدار امنیتی نشان می‌دهد. رمز را از راه دیگری بفرست، مثلاً پیامک یا تماس تلفنی.

## قدم ۸: دستگاه را وصل کن

کسی که لینک را گرفته، [اتصال دستگاه](connect-devices.md) را دنبال می‌کند.

## قدم ۹: اتصال را ببین

ابزار منتظر می‌ماند و نشان می‌دهد:

</div>

```text
✓ client1 is connected from 198.51.100.7. The VPN works.
```

<div dir="rtl">

این نشان می‌دهد کل مسیر کار می‌کند، از جمله فایروال ارائه‌دهنده.

**اگر ندیدی:** بعد از چند دقیقه با Enter انتظار را تمام کن و [کلاینت وصل نمی‌شود](troubleshooting.md#cannot-connect) را ببین.

## قدم ۱۰: اگر ابزار خواست، Reboot کن

اگر نصب کرنل اضافه کرده باشد، ابزار می‌خواهد هر وقت مناسب بود یک بار Reboot کنی. VPN بدون آن هم کار می‌کند، ولی بعدش سریع‌تر است.

</div>

```bash
sudo reboot
```
