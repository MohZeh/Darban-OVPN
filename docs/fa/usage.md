# کارهای روزمره

[بازگشت به README](../../README.fa.md) · [English](../en/usage.md)

منو را با این دستور باز کنید:

</div>

```bash
sudo darban
```

<div dir="rtl">

بالای منو وضعیت سرور، وضعیت [Blocklist یا فهرست گواهی‌های باطل‌شده](glossary.md#blocklist)، تعداد کلاینت‌ها و هر موردی را که به توجه نیاز دارد، نشان می‌دهد.

## روش انتخاب گزینه‌ها

- **در فهرست گزینه‌ها:** خط `Enter: ...` نشان می‌دهد که Enter در این لحظه چه کاری انجام می‌دهد. برای انتخاب گزینهٔ دیگر، `↑`/`↓` یا شمارهٔ آن را بزنید و سپس Enter را بزنید. `Esc` لغو می‌کند. جابه‌جا شدن روی گزینه‌ها به‌تنهایی کاری انجام نمی‌دهد.
- **در پرسشی که پیشنهاد دارد:** Enter مقدار داخل کروشه را می‌پذیرد.
- **در پرسشی که پیشنهاد ندارد:** Enter خالی لغو می‌کند.

پرسش‌های پرخطر همیشه روی پاسخ امن شروع می‌شوند. ارقام فارسی هم پذیرفته می‌شوند.

## افزودن کلاینت

1. `2` یعنی **Create client** را بزنید و نامی مانند `ali-phone` بنویسید.
2. روش فرستادن پروفایل را انتخاب کنید. راهنمای [اشتراک پروفایل](sharing.md) را ببینید.

بهتر است هر دستگاه کلاینت مخصوص خود را داشته باشد تا بتوانید یکی را بدون اثر روی بقیه باطل کنید.

## دیدن کلاینت‌های متصل

**8 Maintenance & diagnostics** و سپس `4` یعنی **Connected now** را باز کنید. بالای منو هم تعداد آن‌ها را نشان می‌دهد.

## دیدن همهٔ کلاینت‌ها

`1` یعنی **List clients** را بزنید. این فهرست کلاینت‌های معتبر و تاریخ انقضای گواهی هر کدام را نشان می‌دهد. کلاینت‌های باطل‌شده پنهان‌اند و ابزار راه نمایش آن‌ها را می‌گوید.

## فرستادن دوبارهٔ پروفایل

مثلاً پس از تعویض گوشی یا تغییر آدرس سرور:

1. `4` یعنی **Share a profile** را بزنید.
2. کلاینت و روش فرستادن را انتخاب کنید.

## ابطال کلاینت

1. `3` یعنی **Revoke client (permanent)** را بزنید و کلاینت را انتخاب کنید.
2. `2` را بزنید تا روی گزینهٔ ابطال برود و سپس Enter را بزنید.

پروفایل این کلاینت روی همهٔ دستگاه‌ها از کار می‌افتد و اتصال فعلی آن قطع می‌شود، در حالی که اتصال کلاینت‌های دیگر ادامه پیدا می‌کند. اگر قطع تنها همین اتصال ممکن نباشد، مثلاً روی سروری که این ابزار آن را راه نینداخته، ابزار این را می‌گوید و می‌پرسد که OpenVPN ری‌استارت شود یا نه؛ ری‌استارت همهٔ اتصال‌ها را چند ثانیه قطع می‌کند. اگر پاسخ No بدهید، اتصالی که باز است ممکن است تا یک ساعت باقی بماند. ابطال برگشت ندارد، ولی بعداً می‌توانید کلاینت تازه‌ای با همان نام بسازید.

## لغو لینکی که استفاده نشده است

`5` یعنی **Active links** را بزنید و لینک را انتخاب کنید.

## حذف پروفایلی که روی سرور مانده است

`6` یعنی **Delete server copy** را بزنید. کلاینت همچنان کار می‌کند و فقط فایل روی سرور حذف می‌شود.

## تغییر آدرس یا پورت سرور

**7 Settings** را باز کنید:

- `1` یعنی **Server address**
- `2` یعنی **OpenVPN UDP port**

پس از تغییر هر کدام، پروفایل‌ها را دوباره بفرستید، چون هر پروفایل آدرس و پورتی را در خود دارد که با آن ساخته شده است. پورت جدید باید در فایروال ارائه‌دهنده هم باز باشد.

## به‌روزرسانی ابزار

دستور نصب را دوباره اجرا کنید، یا در **9 Setup** گزینهٔ `2` یعنی **Check for updates** را بزنید. همین کار با این دستور هم انجام می‌شود:

</div>

```bash
sudo darban update
```

<div dir="rtl">

فقط خود ابزار تغییر می‌کند. OpenVPN ری‌استارت نمی‌شود و کلاینت‌ها تغییری نمی‌کنند. اگر نصب قبلی قانونی را که نسخهٔ جدید لازم دارد، مثلاً محدودسازی TCP MSS، نداشته باشد، به‌روزرسانی آن را هم اضافه می‌کند. برای برگشت به نسخهٔ قبل، در **9 Setup** گزینهٔ `4` یعنی **Restore previous version** را بزنید.

## بررسی وضعیت سرور

**8 Maintenance & diagnostics** و سپس `1` یعنی **Diagnostics** را باز کنید، یا این دستور را اجرا کنید:

</div>

```bash
sudo darban status
```

<div dir="rtl">

اگر یکی از بررسی‌ها مشکلی پیدا کند، کد خروج `1` است و در غیر این صورت `0`؛ بنابراین در اسکریپت هم قابل استفاده است. هشدارها کد خروج را تغییر نمی‌دهند. بررسی‌ها روی خود سرور انجام می‌شوند؛ بنابراین فایروال ارائه‌دهنده و اینترنت روی دستگاه کلاینت را نمی‌بینند. اگر مشکلی گزارش شد، راهنمای [عیب‌یابی](troubleshooting.md) را ببینید.

## حذف ابزار

**9 Setup** را باز کنید:

- `5` یعنی **Uninstall this tool only:** فقط ابزار حذف می‌شود و OpenVPN به کار خود ادامه می‌دهد.
- `6` یعنی **Remove everything:** ابزار، OpenVPN و همهٔ کلاینت‌ها حذف می‌شوند. همهٔ پروفایل‌ها از کار می‌افتند، مگر اینکه پشتیبان را بازگردانید.

برای جزئیات اینکه هر کدام چه چیزی را حذف می‌کند، بخش [حذف](advanced.md#removal) را ببینید.

## فهرست دستورها

</div>

```bash
sudo darban                # menu
sudo darban --no-clear     # menu that never clears the screen
sudo darban list           # active clients
sudo darban list --all     # including revoked clients
sudo darban connected      # clients connected right now
sudo darban status         # diagnostics checklist
sudo darban repair-crl     # publish a fresh blocklist and finish a revocation
sudo darban update         # check for a release and install it
sudo darban about          # version, project address and contact
sudo darban uninstall      # remove only this tool
sudo darban remove-all     # remove this tool, OpenVPN, the CA and profiles
sudo darban version
sudo darban help
```

<div dir="rtl">

منو پس از ۱۵ دقیقه بدون ورودی بسته می‌شود. هر رنگ یک معنی دارد: فیروزه‌ای برای کلیدهایی که می‌زنید، بنفش برای چیزی که باید تایپ یا انجام دهید، سبز و زرد و قرمز برای موفقیت و هشدار و خطا، و قرمز برای گزینه‌هایی از منو که برگشت ندارند. هر پیام نماد و متن خود را هم دارد، پس بدون رنگ هم قابل فهم است. `NO_COLOR=1` رنگ‌ها را خاموش می‌کند. کارها در journal سیستم ثبت می‌شوند: `sudo journalctl -t darban`

</div>
