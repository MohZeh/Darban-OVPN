# عیب‌یابی

[بازگشت به README](../../README.fa.md) · [English](../en/troubleshooting.md)

از اینجا شروع کن. این دستور سرویس، پورت، گواهی‌ها، فهرست مسدودها و شبکه را بررسی می‌کند و می‌گوید چه چیزی مشکل دارد:

</div>

```bash
sudo darban status
```

<div dir="rtl">

<a id="cannot-connect"></a>

## کلاینت وصل نمی‌شود

| علت احتمالی | چه باید کرد |
|---|---|
| پورت UDP در فایروال ارائه‌دهنده بسته است | رایج‌ترین علت همین است. پورت را در پنل ارائه‌دهنده باز کن |
| `ufw` آن را بسته است | `sudo darban status` دستور لازم را نشان می‌دهد |
| آدرس سرور عوض شده است | آن را در **Settings › Server address** عوض کن و پروفایل را دوباره بفرست |
| شبکه UDP را می‌بندد | شبکهٔ دیگری مثل اینترنت موبایل را امتحان کن |
| کلاینت باطل یا منقضی شده است | با `sudo darban list --all` بررسی کن و کلاینت جدید بساز |

## وصل است ولی اینترنت ندارد

| علت احتمالی | چه باید کرد |
|---|---|
| Docker یا برنامهٔ دیگری FORWARD را روی DROP گذاشته است | ترافیک `tun0` را در آن فایروال مجاز کن. با `ufw` خط مربوط در `sudo darban status` را ببین |
| forwarding یا NAT خاموش است | `sudo darban status` آن را در بخش **Network** نشان می‌دهد |
| اپ‌ها کار می‌کنند ولی سایت‌ها باز نمی‌شوند | بسته‌های بزرگ در راه تکه‌تکه می‌شوند و شبکه تکه‌ها را دور می‌ریزد. نصب پیش از `v1.0.0-rc.3` قانونی را که جلوی این را می‌گیرد ندارد: دستور نصب را دوباره اجرا کن. بعد از آن `sudo darban status` خط `TCP through the VPN fits in one packet` را نشان می‌دهد |

<a id="link-fails"></a>

## لینک باز نمی‌شود

| علت احتمالی | چه باید کرد |
|---|---|
| پورت TCP آن در فایروال ارائه‌دهنده بسته است | پورتی را که ابزار کنار لینک نشان داد باز کن |
| لینک منقضی یا لغو شده، یا دستگاه قبلاً وصل شده است | از منوی `4` لینک جدید بساز |
| سرویس بالا نیامده است | دستور زیر را اجرا کن |

</div>

```bash
sudo journalctl -u darban-links.service -n 30 --no-pager
```

<div dir="rtl">

## مرورگر برای لینک هشدار می‌دهد

سرور برای لینک گواهی معتبر ندارد. لینک همچنان رمزگذاری شده است، ولی مرورگر نمی‌تواند تأیید کند سرور مال کیست. برای نداشتن هشدار، گواهی Let's Encrypt را که ابزار با لینک بعدی پیشنهاد می‌دهد بپذیر؛ برای دامنه و IP عمومی هر دو کار می‌کند. [هشدار مرورگر](sharing.md#browser-warning) را ببین.

## نصب سر اولین پرسش می‌ایستد

اگر جواب را تایپ می‌کنی و اتفاقی نمی‌افتد، دستور به شکل `curl ... | sudo bash` اجرا شده است. در این شکل sudo نمی‌گذارد کلیدهایت به پرسش‌ها برسند. Ctrl+C را بزن؛ اگر متوقف نشد، پنجرهٔ SSH را ببند و دوباره وصل شو. بعد دستور [قدم ۳](getting-started.md#step-3) را دقیقاً همان‌طور که هست اجرا کن. چیزی نصب نشده است، چون اولین پرسش پیش از نصب هر چیزی می‌آید.

## نصب تمام نشد

همان دستور را دوباره اجرا کن تا از همان‌جا ادامه دهد. برای برگرداندن همهٔ تغییرات:

</div>

```bash
sudo bash /usr/local/lib/darban/remove-server.sh --yes
```

<div dir="rtl">

جزئیات در `/var/log/darban-setup.log` است.

## منو می‌گوید سرور قابل مدیریت نیست

بخشی از سرور گم یا خراب شده است، مثلاً CA. در این حالت منو فقط عیب‌یابی، به‌روزرسانی و حذف را نشان می‌دهد. بخش گم‌شده را از [پشتیبان](advanced.md#backup) برگردان، یا همه‌چیز را حذف کن و دوباره نصب کن.

## فهرست مسدودها مشکل دارد، یا کلاینتی «هنوز مسدود نشده» است

تا وقتی این رفع نشود، کلاینت باطل‌شده هنوز می‌تواند وصل شود:

</div>

```bash
sudo darban repair-crl
```

<div dir="rtl">

اگر به‌خاطر پایگاه قدیمی CA رد شد، [بازگرداندن پشتیبان قدیمی CA](advanced.md#old-ca-backup) را ببین.

## «عملیات دیگری در حال اجراست»

بررسی روزانهٔ فهرست مسدودها یا نشست دیگری قفل را گرفته است. یک دقیقه بعد دوباره امتحان کن.

## سرعت VPN کمتر از انتظار است

`sudo darban status` خط **DCO kernel module** را نشان می‌دهد. اگر بارگذاری نشده و ابزار Reboot خواسته، Reboot کن. در container این به میزبان بستگی دارد.

## به‌روزرسانی می‌گوید نسخه‌ای برای نصب نیست

هنوز نسخهٔ پایداری منتشر نشده است، پس نسخه‌ای که داری تازه‌ترین نسخهٔ پیشنهادی است. نسخه‌های آزمایشی هیچ‌وقت به‌عنوان به‌روزرسانی پیشنهاد نمی‌شوند. صفحهٔ [Releases](https://github.com/MohZeh/Darban-OVPN/releases) را ببین.

## گزارش مشکل

متن خطا و این خروجی را بفرست. **هرگز** کلید خصوصی یا فایل `.ovpn` را نفرست.

</div>

```bash
sudo journalctl -u openvpn-server@server -u darban-links -n 50 --no-pager
```
