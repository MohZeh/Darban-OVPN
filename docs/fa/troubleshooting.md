# عیب‌یابی

[بازگشت به README](../../README.fa.md) · [English](../en/troubleshooting.md)

از اینجا شروع کنید. این دستور سرویس، پورت، گواهی‌ها، فهرست گواهی‌های باطل‌شده (CRL) و قانون‌های شبکه را روی خود سرور بررسی می‌کند و می‌گوید کدام بخش مشکل دارد:

</div>

```bash
sudo darban status
```

<div dir="rtl">

<a id="cannot-connect"></a>

## کلاینت وصل نمی‌شود

| علت احتمالی | راه‌حل |
|---|---|
| پورت UDP در فایروال ارائه‌دهنده بسته است | رایج‌ترین علت همین است. پورت را در پنل ارائه‌دهنده باز کنید |
| `ufw` پورت را بسته است | `sudo darban status` دستور لازم را نشان می‌دهد |
| آدرس سرور تغییر کرده است | آن را در **Settings › Server address** اصلاح کنید و پروفایل را دوباره بفرستید |
| شبکه UDP را مسدود می‌کند | شبکهٔ دیگری، مثلاً اینترنت همراه، را امتحان کنید |
| کلاینت باطل یا منقضی شده است | با `sudo darban list --all` بررسی کنید و کلاینت تازه‌ای بسازید |

## وصل است ولی اینترنت ندارد

| علت احتمالی | راه‌حل |
|---|---|
| Docker یا برنامهٔ دیگری سیاست FORWARD را روی DROP گذاشته است | ترافیک `tun0` را در همان فایروال مجاز کنید. اگر از `ufw` استفاده می‌کنید، خط مربوط را در `sudo darban status` ببینید |
| forwarding یا NAT خاموش است | `sudo darban status` آن را در بخش **Network** نشان می‌دهد |
| برنامه‌ها کار می‌کنند ولی سایت‌ها باز نمی‌شوند | یکی از علت‌های ممکن این است که بسته‌های بزرگ در مسیر تکه‌تکه می‌شوند و شبکه این تکه‌ها را دور می‌ریزد. نصب‌های پیش از `v1.0.0-rc.3` قانون محدودسازی TCP MSS را ندارند؛ دستور نصب را دوباره اجرا کنید. پس از آن، `sudo darban status` خط `TCP MSS for VPN traffic is limited to 1280` را نشان می‌دهد. اگر سایت‌ها همچنان باز نشدند، DNS را بررسی کنید و اینترنت را با VPN و بدون آن مقایسه کنید |

<a id="link-fails"></a>

## لینک باز نمی‌شود

| علت احتمالی | راه‌حل |
|---|---|
| پورت TCP لینک در فایروال ارائه‌دهنده بسته است | پورتی را که ابزار کنار لینک نشان داد، باز کنید |
| مهلت لینک تمام شده، لینک لغو شده، یا اتصالی با این پروفایل دیده شده است | از منوی `5` لینک تازه‌ای بسازید |
| سرویس لینک اجرا نشده است | دستور زیر را اجرا کنید |

</div>

```bash
sudo journalctl -u darban-links.service -n 30 --no-pager
```

<div dir="rtl">

## مرورگر برای لینک هشدار می‌دهد

لینک گواهی معتبر ندارد. ارتباط همچنان رمزگذاری‌شده است، ولی مرورگر نمی‌تواند تأیید کند که به همین سرور وصل شده است. برای اینکه هشدار نیاید، اگر روی سرور گواهی معتبری برای همین آدرس هست، از آن استفاده کنید؛ در غیر این صورت گواهی Let's Encrypt را بپذیرید که ابزار با لینک بعدی پیشنهاد می‌دهد. هر دو برای دامنه و IP عمومی کار می‌کنند. بخش [هشدار مرورگر](sharing.md#browser-warning) را ببینید.

## نصب در اولین پرسش متوقف می‌شود

اگر پاسخ را تایپ می‌کنید و اتفاقی نمی‌افتد، دستور به شکل `curl ... | sudo bash` اجرا شده است. در این شکل، sudo روی Ubuntu کلیدهایی را که می‌زنید به پرسش‌ها نمی‌رساند. Ctrl+C را بزنید؛ اگر متوقف نشد، پنجرهٔ SSH را ببندید و دوباره وصل شوید. سپس دستور [گام ۳](getting-started.md#step-3) را دقیقاً همان‌طور که هست اجرا کنید. چیزی نصب نشده است، چون اولین پرسش پیش از نصب هر چیزی می‌آید.

## نصب کامل نشد

همان دستور نصب را دوباره اجرا کنید تا از همان‌جا ادامه دهد. برای برگرداندن همهٔ تغییرها:

</div>

```bash
sudo bash /usr/local/lib/darban/remove-server.sh --yes
```

<div dir="rtl">

جزئیات در `/var/log/darban-setup.log` ثبت شده است.

## منو می‌گوید سرور قابل مدیریت نیست

بخشی از سرور، مثلاً CA، گم شده یا خراب است. در این حالت منو فقط عیب‌یابی، به‌روزرسانی و حذف را نشان می‌دهد. بخش گم‌شده را از [پشتیبان](advanced.md#backup) بازگردانید، یا همه‌چیز را حذف و دوباره نصب کنید.

## CRL مشکل دارد، یا کلاینتی «هنوز مسدود نشده» است

تا این مشکل رفع نشود، کلاینت باطل‌شده هنوز می‌تواند وصل شود. این دستور را اجرا کنید:

</div>

```bash
sudo darban repair-crl
```

<div dir="rtl">

اگر این کار به دلیل پایگاه قدیمی CA پذیرفته نشد، بخش [بازگرداندن پشتیبان قدیمی CA](advanced.md#old-ca-backup) را ببینید.

## «عملیات دیگری در حال اجراست»

بررسی روزانهٔ CRL یا یک نشست دیگر قفل را در اختیار دارد. یک دقیقه بعد دوباره امتحان کنید.

## سرعت VPN کمتر از انتظار است

`sudo darban status` خط **DCO kernel module** را نشان می‌دهد. اگر این ماژول بارگذاری نشده و ابزار Reboot را پیشنهاد کرده است، سرور را Reboot کنید. در container، این موضوع به سیستم میزبان بستگی دارد.

## به‌روزرسانی می‌گوید نسخه‌ای برای نصب نیست

هنوز نسخهٔ پایداری منتشر نشده است؛ بنابراین نسخه‌ای که دارید، جدیدترین نسخهٔ پیشنهادی است. نسخه‌های آزمایشی هیچ‌وقت به‌عنوان به‌روزرسانی پیشنهاد نمی‌شوند. صفحهٔ [Releases](https://github.com/MohZeh/Darban-OVPN/releases) را ببینید.

## گزارش مشکل

متن خطا و خروجی دستور زیر را بفرستید. **هرگز** کلید خصوصی، فایل `.ovpn`، لینک موقت یا رمز کلید را نفرستید، و پیش از فرستادن، آدرس IP واقعی سرور را با `x.x.x.x` جایگزین کنید.

</div>

```bash
sudo journalctl -u openvpn-server@server -u darban-links -n 50 --no-pager
```
