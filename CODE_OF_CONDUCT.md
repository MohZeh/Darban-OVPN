# Code of conduct

This project welcomes everyone who wants to use or improve it.

- Be respectful and assume good intentions.
- Keep discussions about the work, not the person.
- Help others without talking down to them.
- Do not harass, insult or publish anyone's private information.

Comments or contributions that break these rules may be removed, and repeated behavior may lead to a block. To report a problem privately, write to [zehtabex@gmail.com](mailto:zehtabex@gmail.com).
